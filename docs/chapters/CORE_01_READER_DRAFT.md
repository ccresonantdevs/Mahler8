# 走進維也納

<p class="chapter-subtitle">一座城市，幾種互不相讓的未來</p>

<div class="chapter-meta-terms"><strong>章名詞語對照</strong>：維也納—德文 <em>Wien</em>（英語 Vienna）</div>

先不要走進宮廷歌劇院。站到 1900 年前後的維也納街頭，你會先聽見鐵輪馬車壓過石板路、車夫甩鞭、小販叫賣、街頭樂師轉動手搖風琴。電車已經開始電氣化，馬車和蒸汽卻還沒有退場。這座以建築、音樂與禮節炫耀文明的帝國首都，當時甚至有人認定它是全歐洲最吵的城市。

如果世紀末維也納真像明信片上那樣優雅，為什麼城裡的人會為了政治、民族、宗教、藝術，連什麼聲音可以留在街上都吵成一團？

這是理解《馬勒第八號》的第一道入口。古斯塔夫・馬勒（Gustav Mahler）以拉丁聖靈讚歌打開作品，又讓約翰・沃夫岡・馮・歌德（Johann Wolfgang von Goethe）的《浮士德》（Faust）第二部終場接手後半。兩種古老而龐大的文化權威，被放進一首規模驚人的現代交響曲裡。這個組合常被一句「世紀末歐洲渴望精神統一」輕輕帶過；然而，馬勒身邊的人根本沒有共享同一個答案。他們甚至連「我們」是誰，都還在爭。

## 環城大道，是一本用石頭寫成的權力字典

十九世紀中葉以前，維也納舊城仍被城牆與外圍空地包住。1857 年，皇帝下令拆除防禦工事；環城大道（Ringstraße）、大型公共建築與住宅區隨後逐步成形。道路改善了交通，也把 1848 年革命後的政治秩序做成一幅可以觀看的城市景觀。

自由主義中產階級相信，憲政、教育、法律與公共文化能帶領帝國走向現代。這種信念直接轉化為環城大道上的各棟代表性建築：國會大廈採用古典希臘風格，呼應古代民主理想；市政廳建築穿上哥德式外衣；維也納大學校舍則以文藝復興風格象徵人文學術復興。每一棟建築，都像在替現代制度安排一個深具權威的歷史源頭。

大道當然很美。它也劃出了誰最有能力替城市定義「文明」。國家機關、文化殿堂與富裕住宅集中在中心，外圍的勞工、新移民與擁擠住房則很容易從這幅宏偉圖像裡消失。

## 1897：同一座城市，同時向三個方向轉彎

到了十九世紀末，人口成長、工業化與選舉政治把更多人推入公共生活。自由主義再也無法自然代表整座城市。1897 年很能說明這種變化：① 基督教社會黨政治人物卡爾・呂格爾（Karl Lueger）公開使用反猶語言動員選民，終於獲任命為維也納市長；② 同一年，追求新藝術形式的分離派（Secession）成立；③ 馬勒也在這一年進入宮廷歌劇院。

三件事都指向「新的維也納」，方向卻完全不同：① 是以排斥性的身分政治動員群眾；② 是正面反抗官方保守的藝術制度；③ 則是由一位出身波希米亞猶太家庭、後來改宗天主教的指揮家，進入帝國最受矚目的官方音樂職位。若把它們硬稱為同一種時代精神，最有意思的衝突反而被抹掉了。

當時崛起的政治力量也沒有結成整齊的反自由主義陣線。基督教社會政治把基督宗教身分與反猶訴求結合成選舉力量；社會主義者聚焦勞工、階級與改革；民族主義者追問，在這個跨民族帝國裡，究竟誰有資格說「我們」。甚至有人嘗試把德意志民族主義與社會主義接在一起，後來又因種族反猶主義而分裂。那些今日看來界線分明的標籤，當時仍在移動、混合、互相爭奪。

## 馬勒身上，同時疊著幾個維也納

1883 年，一位地理學者曾把哈布斯堡君主國描述成由十二個民族、五種宗教教派構成的共同體。帝國各地的人口又隨都市化湧入首都。語言、出生地、教育、政治忠誠與宗教背景彼此交疊，一個人很難只用單一國籍欄位說清楚。

對哈布斯堡猶太人而言，這種交疊尤其明顯。他可能在政治上忠於奧地利，在文化上使用德語、捷克語或波蘭語，同時保有猶太家族與族群身分。馬勒出生於波希米亞（Bohemia），進入德語高級文化，最後在維也納掌握最重要的音樂職位之一；他的朋友則來自加利西亞（Galicia）、摩拉維亞（Moravia）、匈牙利（Hungary）等不同地區。他所生活的世界，從來沒有要求每個身分都朝同一方向排列。

1867 年的宗教自由與公民權改革，確實擴大了猶太人參與公共生活的空間。然而，法律上的解放（emancipation）並未消除社會深層的排斥；即使進入了主流社會的語言、教育與體制，所謂的同化（assimilation）卻沒有帶來真正的安全保障。馬勒在進入宮廷歌劇院前夕改宗天主教，正是這種體制門檻下極為不得已的現實妥協。這項決定能說明他當時身不由己的職業處境，卻無法代表他內心深處真實的信仰全貌。外在的公開身分與私人真正相信什麼，始終是兩件需要分開看待的事。

這個區分之所以重要，是因為反猶主義本身也正在改變。較早的宗教敵意至少在理論上留有出口：改宗之後，宗教身分便可轉換；十九世紀後期的種族反猶論述卻把「猶太」視為不可改變的血統與遺傳，連洗禮也無法抹去這層標籤。在這種氛圍下，改宗雖然跨過了官方任用的體制門檻，卻難以化解社會對其出身的深層敵意。正因如此，我們無法將他的改宗簡化為「從此成了天主教徒」，也不能反過來斷定他私下毫無精神信仰；它所揭示的，是帝國體制、任職門檻與新型態排斥，如何同時加諸在一個人的公開身分上。

這種矛盾，在維也納的城市空間裡被具體放大了。環城大道內側坐落著富裕的文化殿堂，外圍街區卻擠滿了急需溫飽的勞工與移民。隨著選民人數大增，外圍群眾成了改變政局的新力量；市長呂格爾正是看準這點，一方面大舉興建現代化的自來水、交通與市政福利，另一方面卻熟練地用反猶與排外語言動員群眾。這揭示出維也納「現代化」最諷刺的一面：公民參與的擴大，非但沒有帶來包容，反而伴隨著更有效率的系統性排斥。

## 同一張桌上的朋友，後來走向不同道路

馬勒在 1870 年代加入的佩爾納斯托弗圈（Pernerstorfer-Kreis，以恩格爾伯特・佩爾納斯托弗為名的非正式學生朋友圈），正好把整座城市的矛盾縮進了一間客廳。這群維也納大學生一起閱讀華格納、尼采與歌德，熱烈爭辯勞工、民族、社會改革，以及藝術究竟能否改變公共生活。這裡沒有嚴格的章程與會員名冊，成員自由來去，全憑共同的閱讀興趣、深厚友誼與思想激辯凝聚在一起。

然而，這張書桌最終沒能留住一致的答案。昔日同讀一本書的朋友，後來走上了完全對立的道路：有人投身激進的政黨運動，有人隱入神話與宗教更新，馬勒則將一生投注於交響曲。這段青年歷程是理解馬勒極其關鍵的起點——他很早就親眼見證了現實人群的分裂，也深刻體會到思想與政治有多難凝聚共識；「藝術能否創造一個超越對立的共同體」，自此成為他創作生涯中最重大的核心難題。第六章會再仔細重建這張思想網絡。

## 街道太吵，還是某些人被嫌太吵？

現在再回到開頭的聲音。維也納人口從 1850 年約四十三萬增至 1910 年超過兩百萬，交通建設很難同步跟上。電車在 1897 年後才逐步電氣化；皇帝法蘭茲・約瑟夫一世（Franz Joseph I）甚至曾基於美觀，反對在環城大道上方架設接觸線。石板路、馬車、蒸汽電車和缺乏良好懸吊的車輛，確實製造了驚人的聲響。

可是，反噪音運動瞄準的不只機器。1900 年，一位民族學者主張學校應教「第十一誡」：不可製造噪音。1909 年，德國反噪音協會在維也納成立地方分會；它一面要求鋪設新路面、改良交通，一面也想管制小販、街頭音樂、車夫鞭聲，甚至拍打地毯。安靜時段、表演執照和交通規則後來真的改變了人們使用街道的方式。

於是，噪音問題慢慢露出另一層意思：誰的聲音算城市活力，誰的聲音又被當成粗野與落後？現代化帶來更好的基礎設施，也把中產階級對安靜、整潔、效率的偏好寫進公共規則。環城大道用建築安排秩序，反噪音規範則用耳朵安排秩序。

石板路與老舊車輛造成的聲響確實影響睡眠、工作與健康，反噪音措施有它的生活理由。改善共同環境的要求一旦變成規則，也會決定誰必須改變生活方式。基礎設施史與文化權力正是同一場城市改造的兩面。

宗教也沒有隨著電車和新道路憑空消失。它仍活在政黨語言、私人信仰、公共儀式與藝術想像裡，甚至能和最前衛的文化問題坐在同一張桌上。對維也納人而言，現代化是制度與生活條件的改變；現代性是身在其中的經驗；現代主義則是部分藝術家對這種經驗的自覺回應。三者會交會，卻各有自己的歷史。

## 為什麼馬勒需要那些古老文字？

現在，《馬勒第八號》的選材開始顯得不同。拉丁聖靈讚歌、歌德的德語經典、交響曲傳統與龐大公共聲音，從未構成整個時代自然共有的信仰。它們各自帶著權威，也各自帶著衝突：宗教語彙仍在，德語經典從來不完全中立，公共藝術既能召集共同體，也可能把某些人留在「我們」之外。

這些材料一旦進入同一部作品，整座城市尚未回答的問題也跟著進場。下一步要追的，便是其中最醒目的文學權威：歌德的《浮士德》為什麼能讓一代又一代的音樂家，用它談論「現代的人」？
