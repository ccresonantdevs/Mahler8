# 「永恆女性」牽引的「我們」

<p class="chapter-subtitle">終場到底包括了誰？</p>

<div class="chapter-meta-terms"><strong>章名詞語對照</strong>：「永恆女性」— <em>Das Ewig-Weibliche</em>；「我們」— <em>uns</em></div>

如果 Johann Wolfgang von Goethe（約翰・沃夫岡・馮・歌德）寫的是「她引領他上升」，結尾會簡單許多。原文偏偏是：

> *Das Ewig-Weibliche / Zieht uns hinan.*  
> 永恆女性／永恆的女性性，牽引我們向上。

動詞 *zieht* 是「牽引、吸引」，受詞 *uns* 則是「我們」。句子沒有把被牽引者限定為 Faust（浮士德），也沒有標明性別。Gustav Mahler（古斯塔夫・馬勒）又把它交給男聲、女聲與童聲共同唱出。於是，一句常被轉述成「女性拯救男性」的話，在實際發聲時反而把問題擴大了。

這一章沿著一組戲劇動作前進：誰先祈求，誰替別人說話，誰允許上升，誰仍需學習，最後又是誰說「我們」。漂亮同義詞無法替代這些動作。

## 「永恆女性」不是一位角色的名字

《Chorus Mysticus》（神祕合唱）先唱：「一切消逝者，只是譬喻；未能達成者，在此成為事件；不可描述者，在此完成。」最後才接上「永恆女性牽引我們向上」。

德文的 *das* 是中性定冠詞，*Ewig-Weibliche* 則把形容詞名詞化，形成抽象表達。它不是複數的「女人們」，也沒有直接寫成「Gretchen」「聖母」「愛」「美」或「母性」。中文沿用「永恆女性」，方便和既有譯名、總譜與研究對話；閱讀時則要記得，它較接近「永恆的女性性」，意義沒有被任何一位人物用盡。

「牽引」同樣重要。結尾沒有命令人靠意志往上爬，而是說某種力量吸引「我們」。這個代名詞先指向發言的集體，又可能把聽者捲進句子。終場問的便不只是「女性替男性做什麼」，還有誰正在被吸引、朝哪裡移動，以及這個集體能否代表所有人。

## 終場有幾位女性，工作各不相同

第三章已交代 Gretchen（格蕾琴）的受害、牢獄判斷與獨立得救；第四章則看見她在終場為 Faust 代求。此時她的身分是「一位悔罪者，從前名叫 Gretchen」。她看見 Faust 初入新生命、仍被新的白晝照得目眩，便請求由自己教導他。她記得、辨認、代求，也願意陪伴；她不是 Faust 完成冒險後領取的獎賞。

Mater Gloriosa（榮耀之母）是另一個角色。她准許 Gretchen 升往更高領域，並說 Faust 感知她之後便會跟隨。終場大量使用聖母式語彙，祈禱者 Doctor Marianus（馬里亞努斯博士）稱她為「童貞女、母親、女王、女神」。這串稱謂同時帶著基督宗教、詩性與神話色彩，無法直接整理成一套毫無爭議的正式聖母論。

Doctor Marianus 也不是 Faust 得救後的新名字。他是一位獨立祈禱者，呼籲眾悔罪者向上仰望，之後才由《神祕合唱》收束。角色分工由此清楚：Gretchen 代求並請求教導，Mater Gloriosa 准允上升，Doctor Marianus 祈禱與指向，合唱則提出「永恆女性」。這些動作互相配合，沒有合併成一位抽象的「救贖女性」。

## 女性取得力量，不表示全劇已經平等

結尾確實把女性角色放在上升路徑的要位。三位悔罪女性先祈求，Gretchen 再替 Faust 說話；最後一句因此不能被處理成完全沒有性別內容的「精神」或「創造力」。

文學研究者 Carl Niekerk 從《浮士德》第二部反覆出現的身體、生殖與性別意象出發，認為「永恆女性」以象徵方式發生作用。象徵和字典定義不同：一個觀念在形象中持續展開，卻不會被一句解釋耗盡。女性在終場取得強大的象徵位置，整部作品其他地方的男性權力、女性受害與暴力仍然存在。

Niekerk 也注意 *uns* 究竟包括誰。文本沒有說《神祕合唱》只由男性構成；Mahler 的設定更讓不同性別與年齡的聲音共同唱出。這項聲部安排沒有自動生成現代性別平等觀，卻使「永恆女性只對男性發生作用」不再是理所當然的讀法。

## 「吸引」讓結尾保持運動

思想史研究者 Gabriel Trop 借用 *Naturphilosophie*（自然哲學）中吸引與排斥的動態，把 *zieht* 當成入口：永恆女性是終場的一個強大吸引區域，卻未必是解釋整部《浮士德》的唯一宇宙原理。

這個角度也讓 Gretchen 與 Faust 的差異更清楚。Faust 習慣向外擴張、越過邊界；Gretchen 的力量來自對他者敞開、祈求、代求與陪伴。兩人都在移動，朝向他者的方式卻不相同。

Trop 還指出，終場會擾亂簡單的異性戀模式：被牽引的「我們」未標性別，天使的性別呈現也不穩定，Mephistopheles（梅菲斯特）甚至受天使吸引，卻以 *das Ewig-Leere*（永恆空無）回應結尾的肯定。這是後來的哲學與酷兒閱讀，功能在於測試文本內部未被單一答案收服的力量；它不是 Goethe 或 Mahler 留下的思想綱領。

## Mahler 三年後怎麼解釋這句話

1909 年，Mahler 寫信給妻子 Alma Mahler（阿爾瑪・馬勒），把「永恆女性」描述成把萬物神祕地牽向存在中心的力量。他以「安息、目標」對照永恆的渴望與追求，也接受 Alma 將其說成愛的力量；抵達之後，人終於擁有在世上只能渴望的事物，基督徒會稱它為「永恆福樂」。

這封信能讓我們聽見 Mahler 後來的理解：吸引、愛、目標與抵達互相靠近。它寫於作品完成約三年後，不能替 1906 年創作第一刻提供逐字思想紀錄，也不是 Goethe 的官方註解。時間差不使信件失效，卻決定了它能證明什麼。

十九世紀的接受史早已顯示，Goethe 的結尾沒有唯一繼承方式。作曲家 Richard Wagner（理查・華格納）曾以自己的「藉愛救贖」理想批評 Goethe，認為 Faust 沒有及時理解 Gretchen 的犧牲之愛，救贖被拖到死後的宗教圖景才完成。Wagner 的批評證明這個結尾會引發競爭性理解，尚不足以證明 Mahler 直接沿用其答案。

## 終點仍是一個動作

現在可以重新聽最後兩行。「永恆女性」與女性角色、代求、教導、吸引和上升密切相連；它的抽象語法又防止任何一個名詞獨占意義。Mahler 後來把它讀向愛、目標與永恆福樂，Niekerk 與 Trop 則讓性別權力、象徵開放性與多方向的吸引重新浮現。

音樂抵達最後和弦時，Faust 仍不是完成品。他需要辨認 Gretchen、跟隨她，繼續上升。全體唱出的 *uns* 把我們也放進這條關係裡：誰在引領，誰仍需學習，誰被「我們」包含，都不能由華麗終止式代答。

走到這裡，我們已掌握 Mahler 所選文學終場的核心張力。接下來要暫時離開 Faust，回到年輕的 Mahler 身邊：在他尚未寫出《第八號》以前，哪些朋友、書與爭論，已經讓藝術、宗教與共同生活成為可以同桌討論的問題？
